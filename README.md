# lp-02-onsolutions

Landing page estática (HTML + CSS + JS) da **ON Solutions Brasil** para o serviço de **ERP sob medida**, com foco em conversão via WhatsApp.

## Estrutura
- `index.html` — marcação da página
- `css/styles.css` — estilos e responsividade
- `js/main.js` — comportamentos (WhatsApp dinâmico, seleção de desafios, carrossel, header on-scroll, rastreamento)
- `DOCUMENTACAO-LP02-ERP-SOB-MEDIDA.md` — documentação técnica completa, checklist e pendências

## Executar localmente
Abra `index.html` no navegador, ou sirva a pasta:
```powershell
python -m http.server 8080   # depois acesse http://localhost:8080
```

Consulte a documentação técnica para manutenção, rastreamento e a pendência de restauração dos logotipos originais.
